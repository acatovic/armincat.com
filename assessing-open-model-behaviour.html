Assessing Open Model Behaviour

At Funnel we have our own internal data agent platform "Reef". Given a user query, Reef spawns agents that execute a task. Task execution is conceptually a recursive function. The function takes the context and a list of tools as arguments, and either calls itself again, or returns. We can think of each function entry as a model turn. During September 2026 we performed an A/B test where user sessions in Reef are randomly allocated either an Opus 4.8 or a GLM-5.2.
